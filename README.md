## 📝 Title

# 📊 Telco Customer Churn Analysis & Visualization

---

## 📖 Short Description

An exploratory data analysis (EDA) and visualization project using Python (`pandas`, `seaborn`, and `matplotlib`) in Jupyter Notebook to uncover key behavioral and financial factors driving customer churn in a telecommunications dataset.

---

## 🔍 Overview

Customer retention is crucial for the telecommunications industry. This project analyzes the **Telco Customer Churn** dataset to identify why customers choose to leave or stay with the service provider.

### Key Highlights of the Project:

* **Data Cleaning & Manipulation:** Processed and structured customer records, handling values (such as standardizing internet service categories).
* **Exploratory Visualizations:** Built clean, easy-to-understand charts including:
* Overall Churn Distribution (tracking baseline retention vs. loss).
* Monthly Charges Impact (revealing higher churn rates among high-tier billing plans).
* Customer Tenure Analysis (highlighting vulnerability during early onboarding phases).
* Demographic Breakdown (comparing churn trends across gender and internet service types).


* **Actionable Insights:** Provided business recommendations to help mitigate churn, such as introducing long-term contract incentives and addressing pricing pressure on high-end plans.

---

### 🛠️ Tech Stack & Libraries
Language: Python
Environment: Jupyter Notebook
Libraries: pandas, seaborn, matplotlib
